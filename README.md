# Podcast

Задание было выполнено в рамках учебного проекта, короткое описание ниже   
Создайте упрощенную веб-версию проигрывателя подкастов, которая охватывает следующие пользовательские сценарии:
1. Пользователь может увидеть список рекомендованных подкастов.
2. Пользователь может искать подкасты с помощью текстового поиска. Если вы используете тестовый API Listen Notes, результаты поиска могут не соответствовать введенному запросу, поскольку API возвращает предопределенные тестовые данные.
3. Пользователь может открыть подкаст из списка и увидеть страницу с подробной информацией о доступных эпизодах.
4. Пользователь может выбрать эпизод и начать его прослушивание.
5. Пользователь может перематывать эпизоды вперед и назад по временной шкале.
6. Пользователь может продолжать навигацию по приложению (поиск подкастов, просмотр эпизодов), пока эпизод воспроизводится в плеере.
7. Пользователь может добавлять и удалять эпизоды из своего личного плейлиста.
8. Приложение запоминает текущую позицию воспроизведения и содержимое плейлиста после перезагрузки страницы.
